# FreshGuard demo

A browser-only demo of FreshGuard's expiration predictor. It loads a synthetic sample store, simulates shopping days with Monte Carlo tree search, and shows each product's risk of food expiring unsold tonight.

Open `index.html` through any static web host (for example GitHub Pages). It needs no server code, build step or account, and no data leaves the browser.

The donation tracker and pickup planner are in development.
